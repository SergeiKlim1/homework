## Примеры использования функций:

+ Модуль masks
содержит функции для маскировки номера счета и карты:

**get_mask_card_number(card_number: str) -> str**

Принимает на вход номер карты и возвращает в виде маски XXXX XX** **** XXXX 

     Пример: 7000792289606361 -> 7000 79** **** 6361

**get_mask_account(account_number: str) -> str**

Принимает на вход номер счета и возвращает в виде маски **XXXX

     Пример: 73654108430135874305 -> **4305

+ Модуль widget
содержит функции для маскировки номера карты или счета с указанием имени карты или счета и преобразования даты:

**mask_account_card(account_card: str) -> str**

Принимает номер, имя карты или счет и выводит в замаскированном виде

     Пример: "Visa Platinum 8990922113665229" -> "Visa Platinum  8990 92** **** 5229"

**get_date(date: str) -> str**

Принимает дату в iso формате и возвращает в виде дд.мм.гггг

      Пример: "2024-03-11T02:26:18.671407" → "11.03.2024"

+ Модуль processing
содержит функции для фильтрации и сортировки банковских операций:

**filter_by_state(transactions: List[Dict[str, Any]], state="EXECUTED") -> List[Dict[str, Any]]**
Фильтрует список операций по статусу выполнения (например по 'EXECUTED')

      Пример: [
               {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
               {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
               {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
               {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
              ]  
         ->   ->   [
                  {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
                  {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}
                 ]
    

**sort_by_date(transactions: List[Dict[str, Any]], type_sort=True) -> List[Dict[str, Any]]**

Сортирует список операций по дате

      Пример: [
